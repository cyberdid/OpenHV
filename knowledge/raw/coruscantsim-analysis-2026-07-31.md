## 1. Що це

Симулятор планети-міста як **єдиної живої системи**: атмосферна фізика внизу,
соціально-економічна цивілізація посередині, драматургія зверху, кілька вікон
у цей світ.

Головний архітектурний принцип, заявлений і дотриманий: **один всесвіт, один
годинник**. День цивілізації = `phys.step_day()` = рівно 24 години атмосферної
фізики. Ніяких заморожених знімків і паралельних симуляцій.

Порядок кроку:
```
політика → ресурси → економіка → конвої → соціум → щастя →
заворушення → міграція → фракції → персонажі → режисер →
обіцянки → кризові події
```

## 2. Механізми — те, що справді варте уваги

### 2.1 Поле впливу фракцій (`civilization/factions.py`)

Масив `influence[n_factions, n_lat, n_lon]`. Контроль клітинки = `argmax` по осі
фракцій.

```python
bleed_rate = 0.02 * fs.strength * fs.aggression
influence[fid] += bleed_rate * (n + s + w + e) / 4.0     # дифузія до 4 сусідів
...
self.influence *= self.INFLUENCE_DECAY                    # затухання
influence[fid][mask] += INFLUENCE_POP_BONUS * pop_norm[mask] * fs.strength
new_control = np.argmax(self.influence, axis=0)
```

Три властивості: дифузія пропорційна `сила × агресія`, глобальне затухання,
і **густе населення підсилює вплив власної фракції**. Кордони рухаються самі.

### 2.2 Behavior Tree фракції

Селектор із чотирьох гілок у порядку пріоритету, перший SUCCESS виграє:

```
survive → expand → trade → consolidate
```

Ворота жорсткі й читані: `expand` вимагає `strength ≥ 0.4` **і**
`food_per_cap ≥ 10` **і** (`aggression ≥ 0.25` або `expansion_pressure ≥ 0.3`).
`trade` вимагає `trade_openness ≥ 0.4` і `trade_surplus ≥ 5`, шукає найголоднішу
іншу фракцію і віддає `min(surplus × 0.1 × openness, 5.0)`.

### 2.3 Соціум: храповик очікувань і ефект Токвіля

Найсильніша ідея в усьому проєкті.

```python
delta = sol - self.expected_sol
rate = np.where(delta > 0.0, 0.010, 0.0015)          # ростуть у 6.7× швидше
self.expected_sol = clip(self.expected_sol + rate * delta, 0, 1)

gap = clip(self.expected_sol - sol, 0, 1)
self.radicals = clip(0.94 * self.radicals + 0.06 * clip(2.2 * gap, 0, 1), 0, 1)

hope_target = clip(0.5 + 30.0 * sol_trend - 0.35 * radicals + policy_bonus, 0, 1)
self.hope = clip(0.90 * self.hope + 0.10 * hope_target, 0, 1)

self.turmoil = ((self.radicals > 0.55) & (self.hope < 0.45))
```

Чотири окремі ідеї:

1. **Храповик.** Очікування ростуть легко, спадають неохоче — асиметрія 6.7:1.
2. **Радикалізація з розриву, не з бідності.** `radicals` — це EMA розриву
   «очікували мінус отримали». Тому революція приходить не в найгірший момент,
   а коли зростання **зупинилось**. Це Токвіль, і на нього є іменний тест
   `test_tocqueville_effect`.
3. **Надія — окрема вісь**, і вона про **напрямок**, не про рівень: коефіцієнт
   при тренді `30.0`, при рівні — нуль.
4. **Turmoil — двоумовний стан** (`radicals > 0.55` **і** `hope < 0.45`), і він
   не просто «погано», а **блокує логістику**: імпорт їжі −50%.

### 2.4 Конвої та піратство (`transport.py`)

Граф із 8 лор-хабів, кожен зʼєднаний із 3 найближчими. Конвой — сутність із
вантажем, маршрутом і позицією.

```python
risk = 0.01 + 0.10 * unrest[i, j]
if faction_id[i, j] == underworld_id:
    risk += 0.12
if rng.random() < risk:
    lost = convoy.amount_cell_days * 0.6
```

Ризик рахується **у поточній клітинці конвоя** — локальні заворушення плюс
контроль ворожої фракції. Консервація явна й тестована:
`sent = delivered + lost + in transit`.

### 2.5 Політика: голосування територією й обіцянки з дедлайном

Голосування:
```python
score = Σ (частка_території × appeal_закону_для_фракції)
passed = score > 0.0
```
Політична вага **дорівнює контрольованій території**.

Обіцянки — найоригінальніша механіка проєкту:
```python
promise = {"metric": "mean_water_l", "delta": 2.0, "deadline_steps": 40}
# на ухваленні записується baseline
# на дедлайні:
achieved = (current - baseline) >= delta
civ._hope_policy_bonus += 0.06   if achieved
civ._hope_policy_bonus -= 0.08   else
```

Зобовʼязання з терміном, яке потім **звіряється з виміряним станом світу**, і
зламане коштує в **1.33 раза** дорожче, ніж виконане приносить. Плюс бонус
згасає: `_hope_policy_bonus *= 0.95` щокроку — вердикт живе ~20 кроків, а не
вічно.

### 2.6 Режисер (`storyteller.py`)

```python
tension = 0.35*unrest.mean() + 0.25*radicals.mean()
        + 0.25*deficits + 0.15*(1 - hope.mean())
```

Три режими: `cassandra` (крива напруги: тиск → пауза → сильніший тиск),
`randy` (хаос), `phoebe` (довгий спокій). Ескалації `apply_shock`, полегшення
`apply_relief`. Усе — у хроніку.

### 2.7 Персонажі (Shadow-of-Mordor lite)

Кристалізуються **з подій** за таблицею `etype → (архетип, титул, зсув рис)`:
`resource_crisis → Crisis Broker (+ruthlessness 0.25)`,
`control_change → Warlord (+ambition 0.3)`. Мають памʼять про події, що їх
породили, діють на світ (промова, змова, угода), підносяться й падають разом із
фракцією. Cap 40.

### 2.8 Event sourcing

`events.py`: подія `{step, type, actor, lat/lon, place, severity, text, data}`
**без wall-clock** — саме тому реплей детермінований. `build_chronicle.py`
компілює ери (події severity ≥ 0.55) і ролі акторів зі статистики поведінки.

### 2.9 Autoresearch (`autoresearch_planet/`)

Цикл у стилі karpathy/autoresearch: агент редагує **лише** блок параметрів у
`train.py`, ганяє експеримент, дописує рядок у `results.tsv`, лишає краще.
81 експеримент у журналі.

Правило пошуку дослівно: «якщо score покращився — лишити; якщо погіршився —
відкотити й спробувати інше». Тобто **hill-climbing без довірчих інтервалів**.

І там же зафіксована власна проблема провенансу: після Stage-1 перекалібрування
(ціль 250 K → 288 K, переписана фізика) **старі рядки results.tsv непорівнянні
з новими**. Журнал це попереджає текстом, але структурно не захищає.

## 3. Сильні й слабкі місця

**Сильне.** Ідея єдиного годинника витримана. Детермінізм є і тестується
(same seed → same history). Event sourcing зроблено правильно — без wall-clock.
Соціальна модель концептуально глибша за все, що я бачив у відкритих RTS.
Конвої консервативні й це перевіряється. 108 тестів на 8.9k рядків — щільно.

**Слабке.** Немає **парного A/B-порівняння**: єдиний інструмент оцінки — hill
climbing по одному скаляру `score`, без інтервалів, без повторів, без
контролю сідів. Тому жодну зміну не можна прийняти чи відхилити з довірою —
і сам журнал це визнає («старі рядки непорівнянні»). Немає хешу стану для
перевірки, що зміна не зачепила зайвого. Параметри соціальної моделі
(6.7:1, 2.2, 30.0, 0.55/0.45, 0.06/0.08) виглядають підібраними на око, а не
взятими з розподілу.

## 5. Найважливіший висновок

Я цілу сесію доводив, що OpenHV бракує **поля впливу** — і що це головний
однозмінний кандидат після синапсу з лору Рою. Виявляється, **воно вже
написане й протестоване в попередньому проєкті**: 444 рядки, дифузія,
затухання, бонус від густоти населення, argmax-контроль, 18 тестів.

Так само з проблемою, яку зараз міряє DIP-005. Довгий baseline показав, що
101 матч зі 112 застоюється, бо пресинг кламплений у нуль і невдоволення
заморожене. DIP-005 піднімає **константу**. Але в CoruscantSim уже є значно
кращий за конструкцією механізм тієї самої задачі: **розрив між очікуваннями
й реальністю**. Він ендогенний — не залежить від пари, росте сам із того, що
фракція звикла до кращого, — і дає тиск там, де жоден із семи наявних
доданків його не дає.

Іншими словами: OpenHV побудував **вимірювальний апарат**, якого не було в
CoruscantSim. CoruscantSim побудував **зміст**, який OpenHV згубив по дорозі.
Продовження — це не «додати щось нове», а прогнати системи попередника через
матрицю наступника.

## 6. Черга перенесення, за співвідношенням цінність/ризик

1. **Розрив очікувань → радикалізація.** Ендогенне джерело тиску, б'є прямо в
   діагноз довгого baseline. Однозмінний кандидат, вимірюваний наявною
   матрицею. Числа брати **з розподілу**, як робили для DIP-005, а не
   переносити 6.7:1 і 2.2 на віру.
2. **Поле впливу.** Форма вже підтверджена і лором Рою, і турнірними даними
   ORTS, і тепер власним працюючим кодом. Головна робота — цілочисельна
   арифметика під `synchronizedStateHash`.
3. **Turmoil блокує логістику.** Дешево, і замикає соціум на економіку:
   незадоволення перестає бути косметикою.
4. **Ризик маршруту за територією.** У `TradeManager` `risk` уже є, але
   залежить лише від відстані. Формула CoruscantSim (unrest + контроль
   ворога) плюс половина з Endless Sky (цінність вантажу проти охорони) дає
   повну петлю торгівля → війна → торгівля.
5. **Обіцянки з дедлайном.** Оригінально й дешево, але потребує політичного
   шару, якого в OpenHV немає. Пізніше.
6. **Режисер і персонажі.** Наратив, не баланс. Найцінніші для гравця,
   найменш вимірювані матрицею. Останніми.
